# Quiz editor and extraction

Applies to quiz creation/editing, question review, extraction, and result management.

- Group settings by task with clear section headings; keep labels, helper text, and validation next to the relevant field.
- Use the shared `Input`, `Textarea`, `Button`, `Card`, `Badge`, and `Modal` components before adding page-specific controls.
- Use teal for supportive tools and extracted-item highlights; reserve blue for save/publish/continue actions and semantic status colors for validation.
- Keep document preview and question editing resizable at desktop widths; stack panels at narrow widths without clipping controls.
- For long forms, use a consistent 24px section rhythm and retain clear unsaved/loading/success/error feedback.
