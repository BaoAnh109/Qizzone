# Authentication and administration

Applies to login/register, access-denied, teacher approvals, and account management.

- Auth screens use a narrow, centered form with visible labels, password-manager support, and a clear submit state.
- Keep the form width comfortable (about 28–32rem) and use 20–32px card padding depending on viewport width.
- Admin tables must retain readable headers and row actions; on mobile, reflow data into cards or allow an intentional contained horizontal scroll.
- Use teal for informational accent only; use green, amber, and red exclusively for approval/success, caution/pending, and destructive/error states.
- All icon-only actions need accessible names, and all keyboard focus indicators remain visible in light and dark themes.
