# Dashboard and list pages

Applies to student, teacher, and admin dashboard/list routes.

- Keep the page title (`.page-heading`) and one-line context at the top; keep the main task directly below it.
- Use blue for the main action, teal for secondary highlights, and reserve green/amber/red for success/warning/error states.
- Use a fluid page gutter from `.dashboard-main`; cards use the shared `Card` primitive and 16–24px internal spacing.
- Prefer scannable lists, compact metadata, clear empty/loading/error states, and explicit next actions over large decorative hero blocks.
- On mobile, stack cards and filters, let buttons wrap or use full width, and avoid horizontal scrolling.
- Keep text and controls readable in both themes through semantic surface/text/border classes.
