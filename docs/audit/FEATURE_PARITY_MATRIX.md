**Ngày audit:** 2026-11-18
**Nhánh triển khai hiện tại:** `feat/qizzone-v2-backend-aiv3` (worktree cô lập, chưa push)

Trạng thái dưới đây phân biệt code/API test với nghiệm thu production. GitHub Actions run [#158](https://github.com/BaoAnh109/Qizzone/actions/runs/44099953969) đã chạy 18 API tests trên PostgreSQL 17 ephemeral với schema riêng theo test, gồm 100 concurrent submit requests qua hai API host độc lập. Latest local PostgreSQL-backed Release suite passed 39 API + 7 worker tests with zero skips on temporary PostgreSQL 17.12; it includes scheduler, JSONB assignment, concurrency submit, owner-only avatar, AI cancellation and the new 20-attempt capacity race. Full idempotent SQL artifact applied twice on a disposable database; schedule migration downgrade/reapply succeeded. The synthetic migration rehearsal verified digest gating, idempotent import, snapshots, and preservation of a resumable open attempt with no deadline, saved answer and revision. No run has used the intended target/staging. Six Gemini client tests use mocked HTTP. Three earlier Edge E2E runs used a mocked API: admin search/pagination; outbox recovery after API 503 + page reload including fifth option E; and preventing a second tab from overwriting an IndexedDB snapshot while the first tab holds its writer lock. Teacher pagination service tests passed 8/8 with relevant typecheck/lint. Staging integration and E2E for other devices, media, room/join and class assignment remain open.

**Cập nhật working tree:** the latest PostgreSQL-backed Release suite on this branch passed 39 API + 7 worker tests with zero skips on disposable PostgreSQL 17.12, including the PostgreSQL capacity race. Focused tests cover cancellation and scheduling-state mutations. CI on the current worktree SHA, staging migration, browser E2E for these flows and production E2E remain open.
