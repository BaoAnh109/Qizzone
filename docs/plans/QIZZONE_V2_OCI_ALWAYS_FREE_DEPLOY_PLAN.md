# Kế hoạch deploy Qizzone V2 trên OCI Always Free A1

**Ngày nghiên cứu:** 2026-11-18

**Trạng thái:** chủ dự án đã yêu cầu thực hiện; OCI Console xác nhận Free Trial/Free Tier, Account type `Promo`, và home region Singapore. VM shape/capacity/Always Free quota chưa được xác minh; chưa tạo tài nguyên hay chuyển traffic.

**Phạm vi:** backend ASP.NET Core, worker Gemini, PostgreSQL và media V2; frontend tiếp tục ở Vercel.

**Ngân sách:** chi phí thực trả tối đa 0 đồng/tháng. Release đầu là **public beta tối đa 20 phiên thi đồng thời**, không cam kết SLA hay dùng cho kỳ thi quan trọng cho đến khi có bằng chứng vận hành.

OCI công bố A1 Free 2 OCPU/12 GB, 200 GB block volume và tối đa năm volume backup ở home region; nếu không có host capacity phải chờ hoặc thử availability domain khác. VM Always Free ít hoạt động có thể bị thu hồi sau bảy ngày theo các ngưỡng CPU, network và RAM của Oracle. Đây là lựa chọn hiệu năng cao nhất phù hợp Docker Compose sẵn có **trong các phương án $0 đã đối chiếu**, nhưng không phải dịch vụ đảm bảo không gián đoạn. [OCI Always Free resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm), [OCI Free Tier FAQ](https://www.oracle.com/cloud/free/faq/).

Northflank xác định Free Sandbox chỉ để thử nghiệm, Cloud Run tính phí sau free usage, Neon Free hiện có 1 GB/100 CU giờ mỗi project, và Render Free không giữ được PostgreSQL lâu dài. [Northflank pricing](https://northflank.com/docs/v1/application/billing/pricing-on-northflank), [Cloud Run pricing](https://cloud.google.com/run/pricing), [Neon Free update](https://neon.com/blog/neon-free-plan-1-gb-per-project), [Render Free limits](https://render.com/docs/free).

**Điều kiện dừng sớm:** nếu account không đủ điều kiện dùng Always Free, A1 không có quota/capacity trong home region, không có hostname HTTPS ổn định, hoặc không có backup ngoài VM trong quota miễn phí, không thay thế V1 bằng V2. Không nâng cấp sang Pay As You Go hoặc chọn tài nguyên không có nhãn Always Free. [OCI Free Tier FAQ](https://www.oracle.com/cloud/free/faq/).

## 2. Kiến trúc dự kiến

`qizzone.vercel.app` → HTTPS đến Caddy trên OCI A1 → ASP.NET Core API → PostgreSQL private Docker network. Worker đọc job từ cùng PostgreSQL, gọi Gemini qua secret chỉ ở server. Media nằm trên volume bền vững, được backup cùng database. `V1 Supabase` vẫn phục vụ website hiện tại trong lúc kiểm thử và trong cửa sổ rollback.

Khởi đầu bằng **một VM A1 2 OCPU/12 GB** thay vì hai VM 1 OCPU: API và worker có thêm CPU khi tải tăng, PostgreSQL nằm cùng host nên không phát sinh độ trễ mạng giữa API và DB. Giới hạn tài nguyên ban đầu trong [`deploy/.env.pilot.example`](../../deploy/.env.pilot.example): API 1 OCPU/1 GB, PostgreSQL 0.5 OCPU/4 GB, worker 0.25 OCPU/1 GB, Caddy 0.25 OCPU/256 MB. Đây là trần, chưa phải chứng cứ tải. Dự kiến boot volume 50 GB và data volume 50 GB; tổng phải được kiểm tra cùng các volume/backup khác trước khi tạo.

Chỉ Caddy nhận cổng 80/443; SSH giới hạn theo IP quản trị. Không công khai 5432 hoặc API 8080. API dùng DB role hạn chế, migration job dùng role riêng. Caddy cấp TLS cho hostname ổn định. Chưa có domain/hostname đã xác minh cho API, nên đây là một gate thực tế, không điền tên ví dụ vào production.

## 3. Các bước triển khai và điều kiện hoàn thành

1. **Xác minh tài khoản, quota và chi phí.** OCI Console xác nhận Free Trial/Free Tier và home region Singapore. Create VM wizard hiện báo không có shape khả dụng cho image mặc định Oracle Linux 9; thông báo nêu có thể do service limits hoặc capacity, nên chưa xác nhận được A1 Always Free quota/capacity. Instance list/image selector không tải được dữ liệu vì lỗi xác thực. Không tạo VM cho tới khi wizard hiển thị rõ một shape `VM.Standard.A1.Flex` được gắn nhãn Always Free, kèm OCPU/RAM/disk nằm trong quota $0; nếu không có, giữ V1 và không chọn shape trả phí. Tiếp tục xác minh tổng block volume, public IP/quota, hostname API và backup ngoài VM có dung lượng miễn phí.
2. **Khóa bản phát hành.** Trên nhánh `feat/qizzone-v2-backend-aiv3`, đưa toàn bộ file đang WIP vào một commit có SHA xác định. Chạy clean CI đúng SHA: npm audit/lint/build/Vitest, .NET locked restore/audit/test với PostgreSQL, Supabase SQL tests, và build API/worker `linux/arm64`. Build trên host ARM64 sạch bằng `deploy/scripts/build-oci-images.sh`, kiểm tra revision label khớp SHA và lưu các image ID; không dùng tag latest hoặc build của commit cũ. Không dùng OCI Container Registry dưới hạn mức $0 vì image lưu trữ bị tính phí. Frontend cancel/schedule controls and the API's hard limit of 20 active exam attempts are implemented locally. The PostgreSQL-backed Release suite passed 39 API and 7 worker tests with zero skips, including the cross-request capacity race test. This is disposable local PostgreSQL evidence only; clean CI on the exact release SHA, staging load, browser E2E, and the labeled AIV3 corpus remain open. Existing attempts remain resumable, autosavable, and submittable when capacity is full. Các file chính: [CI](../../.github/workflows/ci.yml), [release readiness](../audit/RELEASE_READINESS.md).
3. **Dựng staging tách biệt trên A1.** Cài Ubuntu ARM64, cập nhật bảo mật, Docker Compose, `age` và công cụ backup. Tạo VM/volume trong quota ở home region, chỉ mở firewall như trên. Dùng [`deploy/compose.pilot.yaml`](../../deploy/compose.pilot.yaml) với staging DNS, Firebase test project, DB và secret riêng; chạy migration một lần, rồi kiểm tra `/health/live`, `/health/ready`, CORS, login, upload và một Gemini job với dữ liệu giả. Không đưa secret vào Git hoặc lệnh/log hiển thị. Staging không kết nối V1 production để ghi dữ liệu.
4. **Chuẩn bị cấu hình production trên cùng VM.** Tạo riêng `deploy/compose.oci.yaml`, overlay AI, và [`deploy/.env.oci.example`](../../deploy/.env.oci.example) với volume production riêng, health/restart policy, giới hạn CPU/RAM, log rotation và secret file tuyệt đối ngoài repo. Dùng block volume OCI riêng làm Docker data root; Compose named volumes chỉ bền nếu Docker được khóa phụ thuộc vào mount đó. `deploy/scripts/build-oci-images.sh` chỉ build trên host ARM64 từ checkout sạch khớp full Git SHA, gắn revision label và ghi ra image ID; không dùng OCI Container Registry vì Oracle tính phí cho image lưu trữ ([OCI Container Registry](https://docs.oracle.com/en-us/iaas/Content/Registry/Concepts/registryoverview.htm)). Thêm lịch systemd chạy backup mã hóa và bắt buộc rclone đọc lại bản offsite trước khi xóa bản cục bộ. Destination độc lập, hạn mức $0, retention, Compose config, thời gian backup và restore drill vẫn phải xác minh trên host. Mục tiêu beta: RPO tối đa 1 giờ; chỉ công bố sau khi ghi được thời gian chạy và RTO thực tế. OCI volume backup miễn phí bổ sung thêm một lớp khôi phục, không thay cho bản sao ngoài OCI.
5. **Diễn tập dữ liệu và tải.** Backup V1 rồi thử restore. Dùng `Qizzone.MigrationTool plan` trên bản sao nguồn và target đã migrate; xử lý mọi blocker Auth/Storage/media, kiểm tra digest, bản ghi, đáp án và các attempt chưa submit. Chạy `apply` chỉ trong rehearsal đã cô lập, đối soát trước và sau. Thử 20 học sinh đồng thời: join, autosave, offline/retry, submit, result; không mất hoặc nhân đôi bài làm, không có 5xx trong bài kiểm tra, đo p95/p99 và giới hạn worker để AI không làm chậm ghi đáp án. Nếu muốn 100 học sinh, cần một lượt load test riêng trên đúng cấu hình VM. Chạy E2E ba vai trò và corpus AIV3 có nhãn.
6. **Phát hành có kiểm soát.** Giữ V1 và các attempt đang chạy. Kiểm tra cài đặt Vercel để commit lên nhánh production không tự đổi domain; Vercel hỗ trợ staged production deployment rồi promote thủ công khi tắt auto-assign production domains, nhưng phải xác minh điều này áp dụng cho `qizzone.vercel.app` trong project thực tế. Dùng Preview trỏ đến staging, còn production build trỏ đến API production. Sau khi không còn attempt V1 đang mở, khóa ghi nguồn, đồng bộ browser outbox, chạy kế hoạch migration đã duyệt và đối soát lần cuối. Promote đúng deployment/SHA, kiểm tra login, join, autosave, submit, result, AI import và health. [Vercel staged promotion](https://vercel.com/docs/deployments/promoting-a-deployment).
7. **Theo dõi và khôi phục.** Theo dõi API 5xx/p95, database disk và kết nối, worker queue, autosave ACK, số attempt/submit, chi phí/quota và trạng thái VM. Giữ V1 cùng backup trong cửa sổ rollback. Nếu V2 chưa nhận ghi, rollback Vercel về deployment trước; nếu V2 đã nhận ghi, dừng ghi mới và đối soát/reverse-sync trước khi đổi đường truy cập. Diễn tập mất VM hoặc thu hồi A1 bằng backup ngoài host; nếu không thể khôi phục trong RTO chấp nhận được, beta phải ghi rõ giới hạn và không dùng cho kỳ thi quan trọng. [Runbook hiện có](../audit/ROLLBACK_AND_INCIDENT_RUNBOOK.md).

## 4. Gate phát hành

- **Tài nguyên:** A1, disk, IP, DNS và offsite backup được xác minh ở mức chi phí thực trả 0 đồng; không có cấu hình PAYG.
- **Mã nguồn:** một release SHA sạch, CI và image ARM64 đúng SHA, mọi migration/rollback đã diễn tập trên PostgreSQL đích cùng phiên bản.
- **Dữ liệu:** V1 backup/restore đạt; import không sai lệch dữ liệu bắt buộc; cả attempt mở và câu trả lời còn nguyên; bản backup PostgreSQL + media ngoài OCI restore được.
- **Sản phẩm:** E2E student/teacher/admin, AIV3 corpus và teacher review đạt; API cưỡng chế giới hạn beta 20 phiên đang hoạt động, và load test 20 phiên không mất/nhân đôi bài làm.
- **Vận hành:** HTTPS, health, alert, log redaction, RPO/RTO đo được, thao tác rollback được diễn tập. Không hứa uptime/SLA từ Free Tier.

**Trạng thái hiện tại:** Gate 1 chưa qua. Edge xác nhận tenancy `qizzone`, Free Trial/Free Tier, Account type `Promo`, và home region Singapore. Create VM wizard không liệt kê shape khả dụng cho image mặc định Oracle Linux 9; OCI nêu nguyên nhân có thể là service limits hoặc capacity. Instance list/image selector gặp lỗi tải/xác thực, nên A1 Always Free quota/capacity, nhãn Always Free, và inventory vẫn chưa xác minh. Chưa tạo tài nguyên. `qizzone.site` là domain dự định mua, chưa sở hữu/cấu hình và nằm ngoài hạn mức chi phí $0 hiện tại. Các file Compose, env template, image-build script và systemd backup timer đã được chuẩn bị; Docker Engine không có ở máy làm việc nên chưa render/build. .NET PostgreSQL-backed Release suite qua 39 API + 7 worker test, không skip, trên PostgreSQL tạm cục bộ; CI trên release SHA, staging, data rehearsal và restore trên host chưa có. Đây là chuẩn bị triển khai, chưa phải trạng thái cho phép chuyển production. Tài nguyên Always Free cần có nhãn trong Console và bị giới hạn theo home region ([Free Tier](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm), [Always Free resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)). Không tạo tài nguyên cho tới khi wizard hiển thị rõ tài nguyên Always Free đủ quota và chi phí $0; nếu không đạt gate này, giữ V1 đang chạy và không deploy V2 cho người dùng.
